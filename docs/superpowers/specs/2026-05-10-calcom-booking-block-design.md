# Cal.com Booking Block

**Date**: 2026-05-10  
**Status**: Approved

## Overview

A new TinaCMS page block that embeds a Cal.com booking calendar inline on any page. The user pastes a full Cal.com URL (e.g. `https://cal.com/growandglow/workshop`) and the block handles embedding via the Cal.com JS API for dynamic auto-resizing.

## Files Changed

| File | Change |
|------|--------|
| `components/blocks/cal-booking.tsx` | New block component + TinaCMS schema |
| `tina/collection/page.ts` | Register `calBookingBlockSchema` |
| `tina/__generated__/types.ts` | Auto-regenerated by TinaCMS |

## Block Fields (TinaCMS Schema)

| Field | Type | Required | Default | Notes |
|-------|------|----------|---------|-------|
| `background` | string | yes | `"bg-surface"` | Section background token |
| `title` | string | no | `""` | Optional heading above the embed |
| `url` | string | yes | `""` | Full Cal.com URL, e.g. `https://cal.com/growandglow/workshop` |

No `height` field — Cal.com's JS API auto-resizes the container div.

## Component Design

### URL Parsing

Strip the `https://cal.com/` prefix to get the cal link:

```
"https://cal.com/growandglow/workshop" → "growandglow/workshop"
```

Use `url.replace("https://cal.com/", "")` or parse with `new URL()` and take `pathname.slice(1)`.

### Unique Element ID

Each block instance gets a unique div ID derived from the cal link (with slashes replaced):  
`cal-inline-growandglow-workshop`

This ensures multiple booking blocks on the same page target independent containers.

### Script Loading

On mount via `useEffect`:
1. Check if `window.Cal` already exists — skip script inject if so
2. Otherwise inject `<script src="https://app.cal.com/embed/embed.js">` into `document.body`
3. After load: call `Cal("init", { origin: "https://cal.com" })`
4. Call `Cal("inline", { elementOrSelector: "#<uniqueId>", calLink: "<calLink>" })`

Cleanup: no teardown needed — Cal.com embed persists for the page lifetime.

### Rendered HTML Structure

```tsx
<Section background={data.background}>
  <div className="max-w-screen-md mx-auto">
    {data.title && <h2 className="font-headline ...">{data.title}</h2>}
    <div id={uniqueId} style={{ width: "100%", height: "100%", overflow: "scroll" }} />
  </div>
</Section>
```

## TinaCMS Schema

```ts
export const calBookingBlockSchema: Template = {
  name: "calBooking",
  label: "Cal.com Booking",
  ui: {
    defaultItem: {
      background: "bg-surface",
      title: "",
      url: "",
    },
  },
  fields: [
    sectionBlockSchemaField,
    { type: "string", label: "Title", name: "title" },
    { type: "string", label: "Cal.com URL", name: "url" },
  ],
};
```

## Registration

In `tina/collection/page.ts`, import `calBookingBlockSchema` and add it to the `blocks` array alongside `embedBlockSchema`.

## Edge Cases

- `url` empty or missing: render nothing (`return null`)
- Multiple blocks on same page: unique IDs prevent conflicts
- Script already loaded (navigating back to page): `window.Cal` check prevents double-init
